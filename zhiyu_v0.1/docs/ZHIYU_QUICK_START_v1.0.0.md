# 智御 v1.0.0 · 5分钟快速上手

适用于管理员已完成安装、PostgreSQL/ingress已运行、有操作员身份与已登记 A 档案的本机 Reference。首次冷安装、本地模型/Sensor 的 LIVE A、Docker重启后的START-001处理不计入5分钟。当前正式启动存在已记录缺口，底层停止时先交管理员，不保证5分钟完成。

1. **0:00–0:45 启动与检查。** 在工程根目录设定自己的 `$deployment` 与 `$runtime`，按 [手册第4章](ZHIYU_USER_MANUAL_v1.0.0.md#4-启动智御) 执行 start/status/health/ready。仅 health=ok、ready=ready 才打开 `http://127.0.0.1:18010`，用私密操作员身份登录。
2. **0:45–1:30 概览与事件。** 选有 A 记录的 `m6-real-demo-…` 子环境及 scope-lab-web；先进入“事件”点“重置”去掉旧筛选，再看概览四项KPI，回事件页点记录、进入“完整页”。等待加载及数字动画完成再读数；快速切换若429，稍候重读。
3. **1:30–2:30 决策与验证。** 先“摘要”，再“决策”看 ModelRun、SHADOW 提案、独立 Authorization/Risk 与执行回执，再“验证”看三维结果和有效期。历史结果过期是正确提示。
4. **2:30–3:15 时间线。** “记录”→“在时间线中查看”，点一个真实时间点；注意来源时间/入库时间与非因果限制。
5. **3:15–4:15 回放演示。** 回 `v1-reference-control`→“演示”，在已完成 A 的运行卡点“历史回放”。确认顶部 RECORDED_REPLAY。此操作不启动Worker/模型，也不执行Action；不要点击“开始场景”。
6. **4:15–5:00 生成并保存报告。** 在回放上下文点“报告”，阅读八节草稿，点“下载 JSON”或“下载 Markdown”。保留hash、原as_of、来源及限制；这是未复核草稿。

实际5分钟验证耗时与范围见 [走查报告](FULL_PRODUCT_WALKTHROUGH_v1.0.0.md)。准备不足时不追赶时间、不绕过校验，改由管理员准备后再演示。
