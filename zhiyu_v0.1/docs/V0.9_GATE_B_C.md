## Gate C：时间线、来源图和同快照展开

时间线有明确 DTO：stage / object_type / object_ref / source_ref / actor_source / event_type / status / evidence_refs / timestamp 语义。按真实 datetime instant 排序，保留来源、入库、创建、开始/完成等原字段，不为缺失阶段借用相邻时间。未知时钟与缺失来源明确保留。

图从授权快照的明确外键、关联表和来源字段构建；节点包含类型/环境命名空间。模型推断、SOURCE_ASSERTION、未知 StateRelation 不升级成攻击事实。EVENT_SOURCE / TARGET 同时检查关系行和事件固化角色；冲突保持未解析。没有图数据库、文本实体推断、或隐式攻击因果。
