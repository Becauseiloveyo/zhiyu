# 智御 v1.0 比赛演示脚本

本指南限定 CONTROLLED LAB。最终验收状态以 `V1.0_STATUS.json` 为准；当前候选尚未完成Gate E，不把历史成绩写成当前最终PASS。
比赛前先完成场景验证与封存；现场异常保留原始失败，明确切换 RECORDED REPLAY。

## 操作准备

按 [用户指南](USER_GUIDE.md) 与 [部署指南](DEPLOYMENT_GUIDE.md) 启动同源 Web Console 和独立 Worker。登录操作员，选择本部署登记的控制环境与 `scope-lab-web`，打开“演示”。全新Reference为 `v1-reference-control`，从v0.9恢复则保留原 `v09-demo-control`。界面只提供登记的 A–E，不能填写命令、目标、Capability 或风险覆盖。

各场景依次点击“开始场景”，点击“刷新运行状态”观察 PREFLIGHT → TRIGGER → VERIFY → ARCHIVE。四步完成表示演示流程完成，**实际结果**单独展示，不等同安全 PASS。每次运行的真实数据在 `m6-real-demo-…` 独立环境中；“查看本次事件”直达该轮事实。“历史回放”只在成功封存后出现。

完成后点击“清理本次资源”，等待 CLEAN。之后可“重置并新建运行”：产生新 ID 和新数据环境，原始失败、验证和报告均保留。NEEDS_RECONCILIATION 不自动重发不确定步骤；清理只处理该轮归属的可销毁 Lab 资源。

## 5–7 分钟完整讲解

计时前完成 Lab 启动及场景封存。全部冷启动实时执行通常超过讲解时长；以下明确混合当前事实查看和历史回放，不宣称历史画面实时发生。

| 时间 | 点击与展示 | 解释 |
|---|---|---|
| 0:00–0:40 | “概览”，选择已完成场景的环境 | 指标由当前授权范围的 PostgreSQL 事实计算；没有定义的风险分数和未观测服务显示 UNKNOWN/N/A。 |
| 0:40–2:20 | 回到控制环境“演示”，打开 A 的“查看本次事件”，依次查看证据、决策、验证 | 原始 Sensor → 事件/关联 → Incident → 实际 ModelRun/提案 → 授权与风险 → Action → 三维独立验证。AI 提案不是授权，执行成功不是安全成功。模型默认 OFF；演示显式启用 SHADOW。 |
| 2:20–3:10 | 打开 B 的“历史回放”，切换决策页 | 页头明确 RECORDED REPLAY。脚本模型来源 SCRIPTED_NOT_AI；不存在的能力被拒绝，Action 为零。不是一次真实模型的随机失误。 |
| 3:10–4:10 | C、D 的历史回放，查看验证和状态/重规划 | C 真实停止 Agent，结果 INCONCLUSIVE；D 脚本声称成功，真实业务故障导致 FAIL，并产生有限重规划。独立验证优先于模型说法。 |
| 4:10–4:50 | E 的历史回放，查看模型失败收据、确定性计划和执行 | 模型服务停止后 Gateway 失败，已有确定性基线继续走正式授权与验证。没有偷偷换成假模型输出。 |
| 4:50–5:40 | “报告”，下载 JSON/Markdown | 同一快照、原始时点、来源引用与 SHA-256；报告标记“未复核草稿”，不自动发布或关闭 Incident。 |
| 5:40–6:30 | 回控制环境，展示一次 CLEAN 及 reset 的 predecessor | 清理有实际资源核对；重置新建独立运行并保留历史。指出 CONTROLLED LAB、生产/Cloud/OT/Windows Sensor 未验证的范围。 |

## 2–3 分钟简版

1. 0:00–0:40：A 的封存事件，指出 OBSERVED 证据与真实 ModelRun，页头保持 RECORDED REPLAY。
2. 0:40–1:25：D 的决策和验证，模型声称成功与独立 FAIL 同屏；展示重规划上限。
3. 1:25–2:00：C 的 INCONCLUSIVE 与 B 的拒绝/零 Action。
4. 2:00–2:40：报告下载、原始 as_of、三维验证和限制；说明现场可以启动固定 LIVE 场景，回放不产生 Action。

## 故障处理

- 模型/Sensor 不可用：保留当前 run 的错误或 UNKNOWN。回到已有完成 run 点击“历史回放”，口头说明切换；不要把失败 run 改名为 PASS。
- API/数据库不可用：页面应显示读取错误；不能从缓存健康状态宣称系统正常。恢复后手动刷新或重新登录。
- 403：使用获准环境/Scope；隐藏按钮不是权限控制，后端仍强制校验。
- 无封存记录：不能临时制造样例顶替，展示实际错误和已有验证材料。
- CLEANUP 为 NEEDS_MANUAL：停止新运行，由管理员核对归属和残留。不要删除控制数据库或手工重写 run 状态。

所有讲解结果必须对应当前验收清单中的具体 run_id；本脚本本身不是运行通过证据。
