# v1.0 AI Value Final Position

正式选择：**OPTION B — AI-assisted analysis / planning / recommendation**。

AI 接收有界、脱敏且可追溯的 Incident/Context/Evidence，产生标明模型来源的分析、规划与建议。REFERENCE_GROUNDED 是引用约束通过，不能解释为语义正确；自报 confidence 不作为校准概率。

**closed-loop superiority NOT CLAIMED**。已有 v0.6 G1/G2 对照是 planning-level SHADOW：相同 Context ID/hash、Scope、证据与预算，G2 不执行，Verification=NOT_RUN_SHADOW。G1 的独立验证不能归给 G2；任务集合重叠不是准确率或效率提升。v0.9 的 A–E 展示安全边界，不是严格的同条件闭环优越性实验。本版本不增加自治程度以获得比较成绩。

G0 的冻结定义为“相同原始数据和场景，原有设备/人工步骤，观察总体运维流程变化”。现有材料没有独立、可靠、可重复的 G0 实验基线，正式记录：**G0 NOT INCLUDED IN V1.0 CLAIM**。不声称替代人工的效率提升百分比。

保持 AI default OFF、enabled default SHADOW、AI Proposal != Authorization、Action 经 Authorization/Risk/Gateway、独立三维验证、高风险自主执行0、CONTROLLED LAB。一般模型语义正确性 NOT PROVEN。

原始输入：冻结资料包 `docs/07_实验验收与路线.md`；工程历史 [G1/G2实测](ADVERSARIAL_EVALUATION_v0.6.0.md)、[v0.9验收](VALIDATION_REPORT_v0.9.0.md)。最终 v1.0 只主张稳定原型的可安装、可恢复、可验证和建议辅助能力。
