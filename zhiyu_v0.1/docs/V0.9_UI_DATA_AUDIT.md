## 接入顺序与真实性规则

Gate A 先完成 DTO、当前读授权、一致事务和有界快照的真实 PostgreSQL 测试。
Gate B 才将同一套定稿组件迁入正式工程并替换 data.js 合成来源。
MOCK 数据仅可留在隔离测试 fixture；正式 LIVE 路径不得 fallback 到它。
当前唯一已完成的真实 UI 数据是用户 Logo 与本机布局偏好；上述业务字段均尚未宣称已接入。
